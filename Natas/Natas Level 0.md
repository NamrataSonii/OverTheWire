# Natas Level 0 

**Username:** `natas0`

**URL:** http://natas0.natas.labs.overthewire.org

## Objective

Find the password for the next level, `natas1`.

## Solution

The password for `natas1` is hidden in the HTML source code of the `natas0` webpage.

### Steps

1. Open the Natas Level 0 webpage.
2. Right-click anywhere on the page.
3. Select **Inspect**.
4. Go to the **Elements** tab.
5. Look for an HTML comment containing the password.
